# T05 设备 A：本地姿态工程试跑

日期：2026-10-28。状态：阶段实现完成，T05 保持 Doing。D018 确认本批素材仅用于本地关键点测试；不包含云上传或正式多人评估授权。女性身体多样性仍是主要设计和验证对象，本批不能证明人群效果。

## 实现范围

沿用锁定环境 Python 3.12.14、MediaPipe 1.1.1、PyAV 19.0.1、NumPy 2.5.4、OpenCV contrib 5.0.0.93。Pose Landmarker Lite 资产版本和 SHA-256 由 configs/model-assets.json 追踪，运行前核验；CPU / VIDEO 模式，每次最多 30 秒、1800 帧。

配置版本 pose-prototype-0.1；最多两个模型候选，detection/presence/tracking 阈值均为 0.5。只有一个候选时保留 33 点，多个候选不自动选人，未检出不补点。不输出世界坐标或使用插值。低信号与出框坐标保留为原始证据，但不绘制；非有限坐标记缺失。绘制要求 visibility/presence 均不低于 0.5 且 x/y 在画面内，阈值是待验证工程选择。

保留源帧索引和原始分数毫秒 PTS；模型接口使用四舍五入的整数毫秒，发生时钟碰撞则拒绝而不补帧。缓存键包含源视频哈希、区间、镜像、模型、配置与运行版本；改变输入清除旧结果。结果只保留当前会话，不自动导出私人数据。显示骨架用于人工诊断，未完成 T07 的完整播放/证据交付。

## 验证证据

- 53 项 Python unittest 通过，新增 7 项覆盖无/多候选、低信号/出框/非有限值、模型时钟、契约投影与缓存失效、叠加不改输入、UI 显式运行与失败清空。5 项播放器前端测试通过。
- 5 条真实 H.264/MP4，合计 2,848 帧、约 94.95 秒，完整本地推理完成；未纠正镜像。单次推理计时约 19.9–26.0 秒/片，合计约 114.2 秒，含 detector 初始化和解码，不含完整导入、界面传输与人工查看。仅代表设备 A 当前运行，不能作为跨设备性能承诺。
- 模型输出分类：未检出 552 帧、多个候选 564 帧、单候选 1,732 帧，分母均为 2,848 帧。“单候选”不证明主体正确或单人入镜；不是识别准确率。
- 左腕未满足绘制条件 1,710/2,848 帧；右腕 1,977/2,848 帧。这里同时包含无/多候选、低信号、缺坐标及出框，不等同人工真值中的不可见，也不是错误率；左右为模型标签。
- 重跑一条完整视频，缓存键、逐帧数值与诊断完全一致；只验证这一条在同环境下复现。全部五条 PoseSequence 投影通过 schema，不伪造正式 VideoManifest、参与者或授权记录。
- 真实模型接入 Streamlit AppTest：61 帧区间成功提取，骨架源帧导航和镜像切换清除结果通过。此为框架集成验证，本轮没有新增浏览器视觉验收声明。
- 本地查看三条片的诊断叠加抽帧：可见部分身体点对齐，也发现背景人物被跟踪、遮挡时关节错位和器械上出现虚假骨架。按可绘制点数量选择的帧也会错误，不能把点数多当作质量高。
