## 每次认领与结束

开始前拉取最新 main，读 HANDOFF，确认没有另一台的 Doing 任务；把目标任务改为 Doing 并记录设备后提交推送。处理无网络情况时先保留改动并报告，不能靠覆盖远端解决。

结束时填写：
- 本次任务和设备。
- 变更文件与结果。
- 实际小时及剩余估计。
- 执行过的测试命令、样例版本和结果。
- 阻塞、下一步、相关提交或 PR。

若需要跨机保留未完成工作，可以提交清楚标记的阶段性修改，但状态仍为 Doing 或 Blocked。不得把“计划以后测试”当作验收完成。
