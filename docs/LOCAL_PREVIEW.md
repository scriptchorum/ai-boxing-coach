## 启动与使用

先按 [工程环境](ENGINEERING.md) 安装 Python 3.12、requirements.lock 和本项目。在仓库目录运行：

```powershell
.\start-preview.ps1
```

浏览器打开 http://127.0.0.1:8501 。脚本优先选择安装完整依赖的 .venv；设备 A 已有的 T03 环境也可自动识别。其他环境可指定：

```powershell
.\start-preview.ps1 -PythonPath "D:\你的环境\Scripts\python.exe" -Port 8502
```

也可以不运行脚本，直接使用已安装环境的 Python：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app/main.py --server.address=127.0.0.1 --browser.gatherUsageStats=false
```

1. 在文件资源管理器中复制视频完整路径，粘贴到页面，点击“打开视频”。导入会先完整检查视频，因此需要等待几秒。
2. 默认“联动播放”：播放、暂停或拖动左侧进度条，右侧同步当前浏览器画面。画面时间来自浏览器呈现帧回调；不支持该回调的浏览器会标明近似时间。此模式尚未叠加骨架。
3. 需要精确源帧号时切换“手动逐帧”，使用“上一帧”“下一帧”或帧号输入框。帧号从 0 开始，时间来自解码 PTS；这个模式的原片播放器与源帧输入独立。当前这批视频未开启镜像保存，保持不勾选；确认开启镜像保存时可纠正右侧，左侧始终保留原片。
4. 填写起始和结束帧，两个端点帧都包含。显示的结束时间是下一帧开始时间，或全片结束时间；因此时间区间按左闭右开计算，不使用“帧数÷帧率”。
5. 选段仅保留在当前浏览器会话，不自动裁剪或保存。关闭当前视频、刷新或换片后需重新选择；原视频保持不变。

服务只监听本机回环地址，关闭使用时在启动终端按 Ctrl+C。另一台电脑应先拉取代码、安装依赖并独立启动；视频另行放在该电脑的受控目录，路径无需相同。不要把本地地址当作跨设备共享链接，也不要把视频加入 Git。

## 支持与限制

- 首版入口仅接受 MP4 容器、H.264 编码、8-bit yuv420p、无容器旋转或反射元数据的视频。改文件扩展名不能转换格式。
- 沿用 T04 上限：512 MiB、120 秒、20,000 帧、像素总量不超过 3840×2160。推荐 10–30 秒、720p/1080p 的短片。
- 联动播放暂限 64 MiB，避免过大的组件消息；更大文件仍可用“手动逐帧”（总输入上限保持 512 MiB）。播放器取决于浏览器解码支持，本轮验证当前 Windows 内置浏览器。联动时间用于观看；精确源帧与 PTS 核对使用手动逐帧。
- 联动在浏览器内复制当前帧到右侧 canvas，不逐帧调用 Python，也不生成 RGB 视频缓存；换片或关闭时取消回调、暂停并释放 Blob URL。更改镜像或选段会重新加载联动播放器，播放位置暂不保存。
- 手动逐帧仍从头解码到目标帧，长片靠后帧可能慢，尚无随机寻帧优化。不会缓存整段 RGB 帧；当前会话保留压缩视频与探测时间轴。
- 不自动判定单人、遮挡或动作合格，不推断性别或左右手。人体出框、背景有人和拍摄晃动必须由用户手动避开，后续 T05/T06 再建立可验证的处理。
- 不保存训练历史、不输出动作评分、拳力、伤病或纠错练习。G0–G4 的女性样本与专业验证门禁保持不变。

## 本地关键点试跑（T05 阶段交付）

刷新页面并打开视频，在下方选择稳定、单人全身可见的训练区间，再点击“识别所选区间的人体关键点”。每次最多 30 秒、1800 帧；需要先按 [工程环境](ENGINEERING.md) 下载并校验固定模型。第一次初始化和逐帧处理需要等待，页面显示进度。

完成后找到“播放并查看骨架”，点击这一组左侧视频的 ▶，右侧会随播放显示已有骨架。暂停、拖动也能核对，超出识别区间时不显示骨架。上方原有联动播放器仍只显示原画面。需要精确检查时，再往下调整“骨架核对源帧号”，对照静态原帧和骨架图。改变视频、选段或镜像会清除旧结果，需重新识别；可手动清除，会话刷新后不保留，无文件导出或云同步。

实测出现背景人物被跟踪、遮挡时骨架落在器械上的错误。即使 visibility/presence 较高，也不证明关节真实可见或位置正确。多个模型候选时不自动选人，未检出时不补点；单个候选仍须人工核对。左右只是模型点位标签，不能用来判断出拳手或惯用手。当前不提供动作判断或指标报告。

53 项 Python 测试及 5 条真实片本地试跑通过；这证明流程能运行，不代表女性人群识别效果或 T05 全量验收。详细聚合证据和剩余项见 [T05 记录](verification/T05_DEVICE_A.md)。上方 T04 验证段落是历史记录。

### 连续骨架播放补充

识别结束后自动显示播放区并定位到所选区间开头，点击左侧 ▶ 即可。新播放器仍可浏览全片，仅已识别且能匹配呈现时间的帧显示骨架；没有新一轮模型推理。原片保留音轨。暂停保持最后呈现的画面与骨架，拖动定位时旧画面变暗，等待新帧匹配。

64 MiB 以上视频、非零原始 PTS 起点或不支持精确帧回调的浏览器，使用下方逐帧核对。本轮 54 项 Python 与 8 项前端测试、真实模型 AppTest 通过；自动浏览器检查因工具无法可靠确认 URL 而停止，实际连续播放目视验收待补。背景和遮挡误检尚未解决。
