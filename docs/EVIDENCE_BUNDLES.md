# 本地私人证据帧包

状态：T07 合成基础 `boxing-evidence-frame-1`，2026-11-03。当前只证明导出结构和界面流程可用；没有用真人素材验收，也没有完成 G1 清单、自动关键帧选择或 Demo 报告，因此 T07 保持 Doing。

## 用途与操作

完成本地姿态识别后，在“骨架核对源帧号”选择一帧，先对照原图和过滤后的骨架图，再点击“准备当前证据帧包”。准备成功后点击下载，浏览器得到 `boxing-evidence-frame.private.zip`。采用两步操作是为了避免每次界面刷新都重复压缩高分辨率图片。

ZIP 固定包含：

- `source.png`：按当前镜像纠正设置解码的显示帧。
- `overlay.png`：同一显示帧叠加既有 `display-quality-0.2` 过滤后的骨架；隐藏时可能与原图相同。
- `manifest.json`：源帧号、PTS、当前选段与镜像设置、模型/运行库/阈值版本、模型状态、显示状态和原因码，以及两张 PNG 的 SHA-256。

清单契约见 `schemas/evidence-frame.schema.json`。它不包含本地路径、关键点坐标、人工动作判断或动作分。`run_key` 用来把证据包绑定到同一次视频、选段、镜像、模型和配置，不能用来代替原视频。

## 私密性与边界

证据包包含真实视频像素和骨架估计，属于私人训练资料，只应保存在用户控制的本地目录，不进入 Git、公开网盘或公开报告。下载由用户主动触发，应用不会自动上传或写入历史。

模型状态和显示规则只说明该帧是否有可查看的工程证据，不证明人物身份、动作正确、识别准确或教练结论。当前不会自动挑选关键帧；用户选择源帧只用于可追溯查看。真人规范片/坏片、女性内部覆盖、人工核对和 G1 清单通过前，不能把本功能当作 T07 完整验收。
