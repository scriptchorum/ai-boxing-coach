# 女性搏击视频复盘工具

AI Boxing Coach 面向女性训练者，以女性身体多样性为主要设计和验证对象。先做手机录像的后手直拳离线观察，再逐步验证专业反馈能力。

私有仓库：https://github.com/scriptchorum/ai-boxing-coach

当前阶段：T01 数据契约、T03 工程骨架及 T04 首版受限视频预览已完成。现在能在本机打开已支持的 H.264/MP4、播放原片、逐帧定位并临时选择训练区间；5 条真实视频已验证。T05 已有本地关键点试跑和逐帧骨架核对，5 条片工程测试完成；尚无动作分析、准确率基准或用户试验结果。用户每周约 20 小时，Codex 辅助，目前没有兼职教练。

## 开始工作

1. 阅读 [项目交接](docs/HANDOFF.md) 和 [Codex 约定](AGENTS.md)。
2. 阅读 [执行方案](docs/EXECUTION_PLAN.md)，在 [任务清单](docs/BACKLOG.md) 认领下一项。
3. 开始开发前同步 main，结束后更新交接、提交并推送。

先按 [本地预览使用说明](docs/LOCAL_PREVIEW.md) 运行 `./start-preview.ps1`，浏览器打开本机地址。首版范围由用户在 D017 确认收窄，HEVC、MOV 等格式另行补测。本批素材已确认仅供本地关键点测试；T02 多人女性样本覆盖仍待补齐。T05 保持 Doing，完整验收尚未满足。

默认“联动播放”会让右侧跟随播放、暂停与拖动；识别完成后，在下方新增的“播放并查看骨架”点击 ▶ 可连续查看骨架。精确检查保留逐帧核对。联动模式暂限 64 MiB，较大视频仍可手动查看。另一台没有视频也能继续代码开发和合成测试，真实素材需单独复制。

已有 Python 3.12 环境时，可按 [契约运行说明](docs/CONTRACTS.md#在另一台电脑复现) 安装锁定依赖并运行合成校验。不需要视频、模型权重或密钥。

完整工程环境与模型资产校验见 [T03 工程环境](docs/ENGINEERING.md)，设备 A 结果见 [T03 复现记录](docs/verification/T03_DEVICE_A.md)；视频探测命令、输入限制和扩展待办见 [T04 视频输入](docs/VIDEO_IO.md)。视频预览无需加载姿态模型；点击“识别所选区间的人体关键点”才加载模型。关键点试跑说明与限制见 [T05 设备 A 记录](docs/verification/T05_DEVICE_A.md)。

## 当前产品边界

先显示动作片段、证据帧和描述性时间/重复性指标。观察结果不等于专业动作判错；在取得专业复核前，不提供技术总分、个性化纠错练习或拳力/伤病判断。

女性主体定位贯穿招募、尺度适配和验收，不使用统一“标准女性骨架”。女性样本表现必须单独评估，不以总体均值替代。

代码、文档、锁文件和非敏感配置通过 Git 同步。真实训练视频、身体信息、逐人标注、密钥和本地数据库不进 Git。当前还没有用户训练历史的云端跨设备同步功能。
