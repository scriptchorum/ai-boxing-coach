# 女性搏击视频复盘工具

AI Boxing Coach 面向女性训练者，以女性身体多样性为主要设计和验证对象。先做手机录像的后手直拳离线观察，再逐步验证专业反馈能力。

私有仓库：https://github.com/scriptchorum/ai-boxing-coach

当前阶段：T01 数据契约、T03 工程骨架与双机基础复现已完成；T04 已在设备 B 建立合成媒体探测、逐帧 PTS 时间轴和显示变换，等待真实手机视频验收。尚无姿态/动作分析功能、真实算法基准或用户试验结果。用户每周约 20 小时，Codex 辅助，目前没有兼职教练。

## 开始工作

1. 阅读 [项目交接](docs/HANDOFF.md) 和 [Codex 约定](AGENTS.md)。
2. 阅读 [执行方案](docs/EXECUTION_PLAN.md)，在 [任务清单](docs/BACKLOG.md) 认领下一项。
3. 开始开发前同步 main，结束后更新交接、提交并推送。

当前开发项：T04 视频解码与真实时间轴。核心接口可在本机检查媒体并保留原始 PTS；T02 素材尚待接收与核验，真实手机格式和 G0 素材条件仍待满足。

已有 Python 3.12 环境时，可按 [契约运行说明](docs/CONTRACTS.md#在另一台电脑复现) 安装锁定依赖并运行合成校验。不需要视频、模型权重或密钥。

完整工程环境与模型资产校验见 [T03 工程环境](docs/ENGINEERING.md)，设备 A 结果见 [T03 复现记录](docs/verification/T03_DEVICE_A.md)；视频探测命令、输入限制和当前待办见 [T04 视频输入](docs/VIDEO_IO.md)。当前界面尚不能导入或分析视频。

## 当前产品边界

先显示动作片段、证据帧和描述性时间/重复性指标。观察结果不等于专业动作判错；在取得专业复核前，不提供技术总分、个性化纠错练习或拳力/伤病判断。

女性主体定位贯穿招募、尺度适配和验收，不使用统一“标准女性骨架”。女性样本表现必须单独评估，不以总体均值替代。

代码、文档、锁文件和非敏感配置通过 Git 同步。真实训练视频、身体信息、逐人标注、密钥和本地数据库不进 Git。当前还没有用户训练历史的云端跨设备同步功能。
