# AI Boxing Coach

私有仓库：<https://github.com/scriptchorum/ai-boxing-coach>

当前阶段：已建立双电脑 Codex 协作基础，尚无应用代码；功能范围和技术栈待确定。

## 两台电脑共同使用

每台电脑各保留一份此仓库，使用 GitHub 的 `main` 分支交换已提交的代码和文档。
开始工作前拉取，完成工作后提交并推送，再切换到另一台电脑。

- [双机接入与日常同步](docs/SYNC.md)
- [当前进度与下次接手事项](docs/HANDOFF.md)
- [Codex 工作约定](AGENTS.md)

这套流程通过明确执行 Git 命令同步文件，不是后台实时同步服务。
Git 不负责同步 Codex 聊天记录、登录状态、插件凭据或本地运行环境。
把需要另一台电脑知道的结论、进度和下一步写进交接文档。

## 日常用语

在已经打开本地仓库的 Codex 中说：

> 开始工作：检查 Git 状态，拉取最新 main，阅读 AGENTS.md 和 docs/HANDOFF.md，然后告诉我当前进度。

完成后说：

> 结束同步：更新交接文档，检查本次改动和敏感文件，提交并推送到 GitHub，确认本地与远端一致。

## 文件约定

- 源码和模型定义代码可以正常提交；不要把所有 `models/` 目录一概忽略。
- 原始视频、训练数据和模型权重默认不进 Git，按需另行传输。
- 本地密钥写入被忽略的 `.env`；示例配置用不含真实密钥的 `.env.example`。
- 每台电脑分别安装依赖和设置凭据；确定技术栈后补充依赖清单和启动命令。
